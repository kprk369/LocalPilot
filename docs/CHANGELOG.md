# Changelog

## 0.1.0 — working private MVP

- Isolated Ubuntu Hyper-V workstation with XFCE, xrdp, and Guacamole.
- Private Tailscale HTTPS routing and separate setup, execution, forwarding, and installer identities.
- Local Ollama 27B orchestration, workspace tools, command approval/rejection/cancellation, durable history, and streamed activity.
- Shared-desktop vision/input, fresh-observation checks, and manual takeover/resume.
- Bounded package broker for tree, jq, ripgrep, and Firefox.
- Firefox navigation/form input and real guest-readiness status.
- Dark iPhone Home Screen web app with public-only offline reconnect assets.
- Startup supervision, dynamic VM address discovery, and gateway-aware SSH firewall recovery.
- Private manual file backups with checksum/database verification and non-overwriting staged restore.
- Opt-in fixed-grammar routine-command auto-approval with persistent authenticated setting and audit records.
- Practical task evaluation and read-only operator diagnostics.

## Publication preparation

- Archived one-time repair scripts, old visual concepts, and development history outside publishable source.
- Removed local user paths, private network/VM identifiers, and runtime artifacts from publication candidates.
- Replaced source-embedded VM identity with validated private creation metadata; protected startup tasks pin it explicitly.
- Added example configuration, contribution/security guidance, stronger exclusions, and publication preflight tooling.

Clean-machine installation and full VM/off-device recovery remain unvalidated. Historical evaluation results are documented with their limits; they are not general reliability guarantees.

Publication-cleanup validation: 109 tests passed, two opt-in GUI checks skipped, one upstream TestClient warning. PowerShell setup source parsed successfully. Known-secret/path scans and documentation-link checks passed. These checks do not constitute a comprehensive security audit.
